# 数据来源与模型范围

`pubchem-periodic-table.json` 是 2026-09-19 获取的 [PubChem 周期表 JSON](https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON)，包含118条记录。运行 `node scripts/build-elements.cjs` 可重新生成浏览器数据。

元素名、原子质量、电负性、氧化态和排布来自该快照。缺失数据保留为空。中文名、周期、区块和教学说明在生成脚本中维护。镧系和锕系不强行分配族号。

铹（103）的排布采用 [NIST 元素页](https://physics.nist.gov/cgi-bin/Elements/elInfo.pl?element=103) 的 `[Rn]5f14 7s2 7p1`，修正 PubChem 快照中的旧 6d1 排布。104—118号统一标注为理论参考、实验信息有限。列出的氧化态不保证都是常见或经过实验确认的状态。

电子计数由参考排布展开并求和，不通过简单填充顺序预测全部基态。最外层电子数不自动等同于 d/f 区元素的价电子数。轨道图采用实球谐函数的角向形状，省略径向节点、相对论效应和真实尺度；不是概率密度采样或实际电子轨迹。

无标准天然平均原子量的元素显示同位素参考质量，不将其解释为天然平均值。17个化合物是独立维护的教学实例，不是覆盖118种元素的化合物数据库。
